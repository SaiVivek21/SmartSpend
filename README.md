# SmartSpend

SmartSpend is a personal expense and budget management web application built as a frontend-focused project.

## Features
- Sign up / login demo flow
- Dashboard with income, expenses, balance and monthly budget
- Add, edit and delete income/expense transactions
- Expense categories
- Search and category filtering
- Monthly budget tracking
- Expense charts and reports
- Smart spending insights
- Responsive layout for desktop and mobile
- Browser Local Storage persistence

## Tech Stack
- React
- JavaScript (ES6)
- HTML5
- CSS3
- Chart.js via react-chartjs-2
- Local Storage

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Important
This version is a frontend project and stores data in the browser using Local Storage. It does not use a real production authentication server or external database.
